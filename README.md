# Cricket-Score-Management-System-using-Java-
Cricket Score Management System

A console-based cricket scoring application developed in Java that enables real-time match score tracking, player statistics management, run rate calculation, and match summary generation. The project demonstrates object-oriented programming concepts and core Java fundamentals through a practical sports management application.

✨ Features
Real-Time Score Tracking
Run and Wicket Management
Over Completion Tracking
Boundary Statistics (4s & 6s)
Run Rate Calculation
Live Score Display
Match Summary Generation
Team Information Management
Interactive Menu-Driven Interface
Match Status Monitoring

🛠️ Technologies Used
Java
Object-Oriented Programming (OOP)
Scanner Class
Loops & Conditional Statements
Switch Case
Console-Based UI


📊 Project Highlights
Tracks runs, wickets, overs, fours, and sixes
Calculates run rate automatically
Generates detailed match summaries
Displays live match statistics
Menu-driven user interaction
Demonstrates practical use of Java fundamentals
Clean and easy-to-use console interface
